[UX/UI·플랫폼기획·프로덕트디자인] 트립네스트 (TripNest)

여행과 숙소 탐색 경험을 사용자 중심으로 재구성하기 위해 기획과 UX/UI 디자인에 집중하여 진행한 사이드 프로젝트입니다.

단순 예약 기능이 아닌, 사용자가 여행을 계획하는 전체 흐름을 고려한 경험 중심 플랫폼 설계를 목표로 했습니다.

초기에는 기획자가 참여했으나 중도 이탈로 인해 디자인팀이 개발자와 협업하며 서비스 구조와 기능을 재정의했고, 단순 UI 디자인을 넘어 플랫폼 전반의 방향성을 함께 만들어간 프로젝트입니다.

Problem

기존 여행 및 숙소 플랫폼은 정보는 많지만 사용자 관점의 탐색 흐름이 정리되어 있지 않아 원하는 여행을 찾기까지 많은 시간과 피로도가 발생하는 문제가 있었습니다.

또한 프로젝트 진행 과정에서도 기획 공백이 발생하며 서비스 방향성과 구조가 불명확해지는 상황이 있었습니다.

Approach

디자인 리드로서 프로젝트의 방향성을 재정립하고, 개발자와의 긴밀한 협업을 통해 서비스 구조를 재설계했습니다.

사용자의 실제 행동 흐름을 기준으로 ‘탐색 → 선택 → 결정’으로 이어지는 UX 구조를 정의하고,

기존의 정보 나열 방식이 아닌 여행 테마와 경험 중심의 탐색 구조로 전환했습니다.

또한 디자인팀이 기획 역할까지 병행하며 정보 구조(IA), 기능 흐름, 화면 설계를 함께 진행했습니다.

Solution
  • 서비스 전체 구조 및 사용자 흐름(UX) 재설계
  • 여행 테마 기반 정보 구조(IA) 기획
  • 메인 페이지 및 주요 화면 UX/UI 디자인
  • 숙소 및 콘텐츠 카드형 UI 시스템 구축
  • 필터 / 정렬 등 사용자 인터랙션 설계
  • 반응형 웹 UI 디자인
  • 디자인 시스템 구축 (컬러, 타이포그래피, 컴포넌트)
  • 개발자 협업 기반 기능 정의 및 화면 설계

여행 탐색 경험을 사용자 중심으로 재설계하기 위해, 디자인 리드를 맡아 기획부터 UX/UI까지 주도적으로 완성한 팀 프로젝트입니다.
